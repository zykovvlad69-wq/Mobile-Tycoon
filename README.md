# Mobile Tycoon — Godot 4 project

## Что внутри
- Главный экран в формате 16:9 с адаптивным UI.
- Приложения: контейнеры, маркет, коллекция, банк, ивенты, профиль, лаборатория, аукцион, настройки.
- 50 моделей смартфонов в каталоге, внутриигровая покупка/продажа.
- Начальный капитал 50 000 ₽, XP/уровни, ежедневный ивент бонус.
- 5 сменяемых цветовых обоев, сохранение прогресса через ConfigFile.
- Стиль интерфейса: темные glass-like панели, округлые карточки и цветные иллюстрированные значки приложений.

## Открытие
Импортируй папку проекта в Godot 4.3 или новее и запусти `main.tscn`.

## Сборка Android
В Godot настрой Android export templates и Android SDK, затем Export Project → Android. Для облачной сборки через GitHub Actions добавь Android export preset и шаблонный workflow; сборка APK требует Android SDK и экспортных шаблонов Godot.

Это базовая играбельная версия проекта; визуальные изображения смартфонов пока представлены карточками/типографикой, а не фото-ассетами.
